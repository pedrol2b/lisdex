# Mode Badge on the Menu Bar Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An optional Settings → Appearance switch (off by default) that badges the menu bar icon with ∞ / clock / calendar for how the current session ends.

**Architecture:** Core decides the badge (`MenuBarBadge.resolve(session:mode:)`) and the resource name; 18 new template glyphs come from the Figma component set as SVGs through the existing `make icons` pipeline; the app only passes the badge into `MenuBarIcon` when the setting is on.

**Tech Stack:** Swift 6 SwiftPM, Swift Testing, AppKit/SwiftUI, `scripts/render-svg.swift`.

**Spec:** `.context/specs/menu-bar-mode-badge.md`

## Global Constraints

- Must compile with Swift 6.3 (Xcode 26): bind controls with `Bindable(model).x` properties in `AppModel+Bindings.swift`; no `@Entry`; no `print`, use `Log`.
- Decision logic in `Sources/LisdexCore` (Foundation only) with tests.
- Menu bar art: SVG sources in `assets/menubar/`, exports regenerated by `make icons`, never hand-edited (ADR 0003). Black + alpha only.
- Setting off by default; settings without the key decode as off.
- Pill glyphs 20 × 18 pt, mug and bulb 18 × 18 pt (icon width never changes when badges are on).
- Run `make format` before committing (lefthook pre-commit); conventional commit messages.

## Review Focus

1. Settings saved by 1.2 (no `showsModeBadge` key) → badge stays off. Test: `AppSettingsTests.modeBadgeMissingKeyIsOff` (Task 1).
2. A user session started with its own length (`lisdex://on?minutes=90`) while the mode is Indefinitely → clock, not ∞. Test: `MenuBarBadgeTests.fixedLengthBeatsMode` (Task 1).
3. App or Focus session while the mode is Schedule → ∞. Test: `MenuBarBadgeTests.appAndFocusAreUntilStopped` (Task 1).
4. A badged resource with no SVG in `assets/menubar/` → falls back silently to an SF Symbol in the app. Test: `MenuBarAssetTests.everyIconHasAnSVG` (Task 2).
5. Badged pill SVG exported at Figma's 18 × 18 instead of 20 × 18 → the icon jumps width. Test: `MenuBarAssetTests.badgedCanvasesMatchUnbadged` (Task 2).
